# Checklist answers

Point-in-time YES / NO / NOT_READY for every row in `merged_draft_v8.1.csv`, using only data known before **09:25 ET** on the date asked.

Live viewer: https://sroyaltyy.github.io/checklist-answers/

Local: `cd docs && python3 -m http.server`

Data files live under `docs/data/<TICKER>_<YYYY-MM-DD>.json`. Regenerate with `engine/answer.py` then `engine/export_json.py`.
